# Shashwat Bikram Singh — Official Developer Portfolio

A modern, high-performance developer portfolio built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, and **Three.js**. Features an interactive 3D WebGL background, tactile cream & caramel editorial aesthetics, multi-page routing, and comprehensive deep-dive case studies.

## ✨ Highlights & Architecture

- **Visual Aesthetics**: Curated cream and caramel palette (`#FAF6F0`, `#2C1E18`, `#B87333`, `#C8965A`), Newsreader serif typography, subtle ambient grain overlay, and glassmorphic cards.
- **3D WebGL Background**: Custom Three.js interactive canvas scene featuring geometric torus knots, icosahedron wireframes, and ambient floating amber particle constellations that react to mouse movements and scroll velocity.
- **Dynamic Multi-Page Architecture**:
  - `/`: Hero introduction, status badge, key metrics, social connectors, curated project showcases, technical skills matrix, and deep-dive portals.
  - `/about`: Narrative biography, core engineering tenets, quick facts, comprehensive skills breakdown, and "Beyond Code" personal interests.
  - `/experience`: Chronological engineering journey, DSU Hackathon Runner-Up honors, academic tenure at Jain University, and verifiable credentials.
  - `/projects`: Curated engineering index with quick briefs and mockup thumbnails.
  - `/projects/[id]`: In-depth case studies with problem & solution analysis, computational methods, end-to-end stage workflows, technology ecosystems, and deliverables (HackaMate, MEDEQUIP, PCA Classification Research, Ghumau, AlertNet).
  - `/contact`: Direct interactive inquiry dispatch with copy-to-clipboard email and instant client fallback.
  - `/api/contact`: Next.js server route handling contact dispatches.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```

### 4. Type Checking
```bash
npm run typecheck
```
